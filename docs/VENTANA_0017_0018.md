Lista de pasos para aplicar **juntas** la 0017 (índice único de serie de equipos) y la 0018 (acciones propias del enlace para nueva contraseña en la auditoría). Este documento solo prepara la ventana: **no la autoriza**. Se ejecuta únicamente con la orden expresa de la persona responsable, y los comandos los corre quien tenga el entorno privado de producción.

Detalle técnico de cada migración y del operador: [EVOLUTION_RELEASE_OPERATOR.md](EVOLUTION_RELEASE_OPERATOR.md). No usar el migrador genérico ni SQL manual de escritura sobre producción.

## Qué cambia y qué no

| | 0017 | 0018 |
| --- | --- | --- |
| Efecto | crea el índice único `customer_assets_owner_serial` | amplía la lista cerrada `security_audit_action` con 2 acciones |
| Datos | no toca filas | no toca filas; la tabla sigue de solo agregar |
| Riesgo propio | falla si hay series repetidas en un mismo espacio (`23505`) y se revierte entero | falla si la restricción fue alterada a mano (`unexpected_audit_constraint_replacement`) |
| Sin la migración | el código ya impide series repetidas | la app seguiría usando las etiquetas antiguas |

Duración esperada: segundos. Mientras corre, las tablas públicas se bloquean con un plazo de espera de 3 segundos; una petición puede esperar un instante o recibir un conflicto.

## Si algo sale mal

| Situación | Qué hacer |
| --- | --- |
| La auditoría o la simulación fallan | No aplicar. Nada cambió en producción. Revisar el código de error con la persona responsable; no editar SQL ni el diario. |
| La comprobación de series devuelve filas | Detener. Corregir las series desde Equipos y repetir. |
| `unexpected_audit_constraint_replacement` | Alguien cambió la restricción a mano. No forzar: investigar quién y por qué antes de continuar. |
| Falla la aplicación con error claro | Se revirtió entera (transacción única). Producción queda como antes; anotar el código y no reintentar a ciegas. |
| `commit_outcome_unknown` | Detener. Auditoría del mismo prefijo con conexión nueva antes de cualquier acción. |
| Problema en la app después de aplicar | Volver al despliegue anterior de Vercel; **no** revertir 0017 ni 0018 (son compatibles hacia atrás). La restauración de un respaldo es un procedimiento aparte, con su propia autorización. |
